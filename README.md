# linux_network — Networking Lab

This repository contains a networking lab report and supporting screenshots.

Contents
- `report.md` — lab write-up and results ([open](report.md)).
- `screenshots/` — images referenced in the report ([open folder](screenshots/)).
- `LICENSE` — GNU GPLv3 for this repository ([open](LICENSE)).

How to view
- Open [report.md](report.md) in your editor or Markdown viewer to read the full report.
- Open images from the [screenshots/](screenshots/) directory to see command outputs and configurations.

Notes
- The report contains step-by-step parts: ipcalc, static routing, iperf3, firewall, static routing lab, DHCP, and NAT.
- No build is required — this is documentation and screenshots.

Contact
- For questions about this repository, open an issue in the project or comment in the report.
